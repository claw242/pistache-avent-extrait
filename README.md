## Le livre complet

Le calendrier complet, c'est 24 jours : une énigme et un petit jeu par jour (labyrinthes, mots mêlés, sudokus 4x4, messages codés). Chaque jour donne une lettre, et les 24 lettres forment la phrase secrète de Pistache.
